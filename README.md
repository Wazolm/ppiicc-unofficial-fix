# PPIICC (Unofficial Bugfix Archive)

> **非官方修改版 / Unofficial Modified Version**  
> 本项目为 PPIICC 工程文件的非官方 bug 修复留档，**与原开发者无任何关联**。  
> 原应用：PPIICC — 简洁易用的 Android 长截图拼接工具。

## 项目简介

PPIICC 是一款 Android 平台的长截图拼接应用，能够自动识别多张截图中的公共区域（如状态栏）并进行裁剪，拼接成一张完整的长图。本仓库是用户自行修复其中某个 bug 后的工程文件留档，不提供官方支持。

## 修复内容

- 修复了 **删除预览图片之后再次点击“拼接”导致APP崩溃的bug**。  
- 修改范围：仅涉及上述 bug 相关代码，其余功能保持原状。

## 与原项目的关系

本仓库**不是** PPIICC 的官方 GitHub 仓库。原应用为免费软件，但源码并未在 GitHub 上公开维护。本仓库中的工程文件由用户基于可获取的版本进行 bug 修复后整理上传，仅供**学习、参考和留档**使用。
